### Instructions

1. Open **WORDUMBER**.
2. Run `Wordumber.exe`.
3. Enter your word in the input box.
4. Select your typing mode:
   - **Genius Mode** – Faster and types long words (use if you want to show off)
   - **Simple Mode** – Slower and types short words (recommended in end game)
5. (Optional) Check **Humanize**:
   - Adds realistic delays and mistakes
   - **0.00001** for fast typing
   - **0.001** for long words / struggling behavior
   - If you don't use Humanize, you might get caught
6. After entering the word, press **Enter** or click **Search**  
   (Pressing Enter is better — only types on your turn)

_**Tip:** Keep settings realistic for safer, human-like behavior._
